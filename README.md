# 在庫管理システム

## 背景

社内の在庫状況をリアルタイムに把握するためのシステムです。対象は自社倉庫の現物在庫のみです。

## 想定ユーザー

- 倉庫管理者
- 営業担当

画面は担当に関係なく同一です。権限差はありません。

## 主要機能

- 在庫の入出庫管理
- 在庫状況のリアルタイム表示（入出庫の登録直後に画面へ反映する）
- 在庫アラート機能（安全在庫割れ時に通知する）

## 在庫の単位

SKU（品目）単位で管理します。

## タスク

### 在庫の入出庫管理

- [ ] SKU（品目）マスタの登録・一覧
- [ ] 入庫登録（SKU・数量）
- [ ] 出庫登録（SKU・数量）
- [ ] 入出庫履歴の表示

### 在庫状況のリアルタイム表示

- [ ] SKU単位の現在庫数量の表示
- [ ] 入出庫登録直後の在庫数量の再計算・画面反映

### 在庫アラート機能

- [ ] SKUごとの安全在庫数の設定
- [ ] 現在庫が安全在庫を下回ったかの判定
- [ ] 安全在庫割れアラートの画面表示
